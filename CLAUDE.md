# CLAUDE.md

This project's instructions live in [AGENTS.md](AGENTS.md) — the same content, in the open cross-tool format (also read by Cursor, GitHub Copilot, Windsurf, Codex, and others) so it isn't duplicated per tool. This file exists only so Claude Code loads it with full `CLAUDE.md` semantics (shows up in `/memory`, `InstructionsLoaded` hooks fire, picked up via `--add-dir`) instead of the slightly reduced set that applies when Claude Code reads a bare `AGENTS.md` directly.
